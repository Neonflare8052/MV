# 恢复同心圆展开 · 运动曲线修订

独立第四版，原曲 33.4–40.7 秒，7.3 秒，1920×1080 / 60 fps，原曲音轨。

## 本次修正

- 保留 AI 的点云同心圆。承接白球的半透明矢量圆环在 37.0667 秒退场，点云圆体保持可见。
- 参考原版 `claude/film/shots/s03_self.py` 的映射方式，冻结圆周角度，将每一圈点按角度次序映射到一条正弦曲线上，各圈对应不同深度。37.10–38.55 秒逐层展开，外圈先行、内圈随后。点的位置连续变化，并有向纵深卷开的弧度。
- 摄影机坐标改变时，同时变换尚未展开的点云圆体，使其屏幕形状与位置衔接。避免把点云圆切掉或突然挪到一侧。
- 白球飞入时使用更明显的弯曲路径与纵深变化；接住后放缓，再沿半圈加速，绕行仍为 180°。
- 白球沿切线离开后向前方拱出，第二段飞行加入弧形侧移与短暂浮起，最终在 38.93 秒落到提前展开的切面。
- 摄影机改为一条连续的三维 Bézier 弧线，以连续加速度起落，经过落地点时不停顿。

点云高度场、切平面和落地白球共用接触关系。落地后轻微下沉、恢复稳定，随后两片相邻切面展开。

`check_motion.py` 检查入画、180° 绕行、速度变化、矢量环退场后点云圆保留、展开时长、摄影机衔接及落地接触；`verify.py` 检查成片规格、解码、三处音频同步和原文件哈希。

本次修改仅写入这个独立目录，第三版的文件哈希一致。校验发现原工程 `claude/film/master.py` 在制作期间有同步更新（14:18:13），本打样没有读取、执行或写入该文件。报告保留这项哈希差异，所以合并检查 `passed` 为 false；成片、轨迹和音画检查另记为 `media_passed: true`。原始哈希未被重设。
