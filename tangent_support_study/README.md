# 点云与矢量：切线承托打样

对应原曲 35.0–40.7 秒，5.7 秒，1080p60，原曲音轨。

AI 的圆与正弦波保持点云表现。白色几何体沿用 YOU 的身份：波面展开时它悬于上方；38.43 秒起，局部矢量切线从接触点向两端展开；38.60–39.03 秒 YOU 降落到切线上；随后 YOU 沿曲线方向移动，矢量切线持续贴合并承托它。周围切线逐步显现。

铜色矢量细面是切线的窄幅延伸，用于让承托可见。它的中心线使用原波形第 18 层的实际导数。YOU 的球心位于切点沿法线一个半径处，保持实际接触。镜头改为稳定的斜前方视角，让落下与移动可以被看清。

本打样集中验证“你可以坐在我的切线上”，没有加入重复主体的背景、歌词或参数标注。原始工程与之前版本保留。

`check_contact.py` 用原曲线的有限差分检查切线方向与接触距离；`verify.py` 核验视频规格、解码、三处音频同步和原始输入哈希。
