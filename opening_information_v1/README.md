# Opening information study v1

独立试作：从开头到 A.D／B.C 后的模拟器转场，59.2167 秒，1920 × 1080，60 fps，原曲音轨。没有歌词字幕。

原始文件只读。`base/` 是所需源码与数据的独立快照；修改与输出全部位于本文件夹。原始输入的 SHA256 保存在 `source_manifest.json`，导出后由 `verify.py` 再次核对。

## 这一版的理解

保留现有几何、全部运镜、切点和音乐节奏。采用白色与铜色的空间标记，把说明落在发生动作的位置。YOU 用菱形、ME 用圆形、LOVE 用不稳定的十字标记。标注会随镜头投影移动，并在有限的阅读窗口退出。

| 时间 | 新增信息 |
|---|---|
| 6.00–7.40 | 输入 YOU、模型 ME、沙盒权限 |
| 10.15–12.50 | 实际写入层数、已有激活树上的一条连通路径 |
| 17.00–20.40 | 当前音频模块及源数据采样读数 |
| 27.40–29.60 | LOVE 状态、持续前进的音频时间与停顿的处理时间 |
| 30.15–33.30 | YOU 的选中位置与参考原点 |
| 34.60–36.90 | ME 所在圆的半径、周长与投影尺 |
| 38.20–40.65 | 所在波形、局部切线与实际斜率 |
| 41.55–44.20 | LOVE 到 YOU 的几何距离、流向与接收边界 |
| 44.45–46.70 | 奇次谐波数量、二值化与零线采样标记 |
| 47.80–51.30 | 实际视野开角、可见比例和开角尺 |

新增信息窗口合计 25.65 秒，占片段 43.31%。这是按时间统计的改动范围；并非画面像素或源码行数的比例。A.D／B.C 的历史场景及后续转场按原版保留。

几何单位 `u` 为场景单位。音频读数来自已有的特征数组，层数和时钟来自场景状态。模型、token 和沙盒属于影片的叙事设定。保留的信号形变是正弦到方波再到数据，新增标注按谐波与二值化描述。

## 实现与复现

复用原有 ModernGL 3D 着色器和实例化点阵；每帧 4 个运动模糊采样，保持现有景深与调色。空间标注使用同一相机投影，经过调色后合成，维持细字与尺寸线的清晰度。FFmpeg / NVENC 编码。

使用现有 `train_cel_test/_vendor` 的 ModernGL 运行依赖与工作区 `tools/` 的 FFmpeg，不需要修改或安装到原项目。

```powershell
& '%USERPROFILE%\.cache\codex-runtimes\codex-primary-runtime\dependencies\python\python.exe' -X utf8 '.\opening_information_v1\render.py'
& '%USERPROFILE%\.cache\codex-runtimes\codex-primary-runtime\dependencies\python\python.exe' -X utf8 '.\opening_information_v1\verify.py'
```

`verification.json` 记录实际规格、完整音视频解码、三处音频同步与原始输入核验。`encoded_contact_sheet.jpg` 来自编码后的成片抽帧。

本次导出核验通过：3553 帧，59.217 秒，完整音视频解码成功；0.6、28.2、55.0 秒三处采样均为 0 ms 偏移，最低音频相关度 0.9993；11 个受保护输入的 SHA256 全部一致。音频比对从头解码后截取，保留 MP3 的解码历史。
