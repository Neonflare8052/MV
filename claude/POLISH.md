## 技术方案（草案，约束：不做精细建模）

现有工程只有约 2400 行：moderngl 画无倒角方盒网格 + PIL ImageDraw 画 2D，无后期。质感差的根源在此。

方针：少建模，多打光。质量来自光照、材质、景深、运动模糊和调色，而不是网格细节。

| 层 | 方案 | 替代 |
|---|---|---|
| 3D | GLSL 有向距离场（SDF）光线步进：几何由数学公式组合，自带圆角、软阴影、AO；体积用噪声场 | moderngl 方盒网格 |
| 2D | 2D SDF 着色器（线、弧、圆，完美抗锯齿、自带辉光）＋ skia-python（文字排版、路径） | PIL ImageDraw |
| 后期 | 统一后期 pass：辉光、景深、颗粒、暗角、色差、调色；运动模糊用每帧多子帧时间采样 | 无 |
| 卡点 | librosa 起音／节拍分析，生成 cue 表 | 仅 LRC 起点 |
| 宿主 | 沿用 Python + moderngl 离屏渲染 + NVENC | — |

规避建模的镜头手法：特写只拍少数细节（孔列、刃口、表针）；剪影与逆光；浅景深与雾；暗调布光。
时代剪影（维特鲁威人、聚落、蘑菇云）用统一的 2D 版画／线刻风格，不做 3D。维特鲁威人可用公有领域原图（需下载，须先征得同意）。
