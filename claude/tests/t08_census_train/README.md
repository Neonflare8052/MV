源时间起点：02:42.632。主体动作完成于原镜头切点 02:46.016；样片额外保留约两秒，展示列车沿弯道接近工厂。

- `census_train_study_1080p60.mp4`：5.383 秒，323 帧，1920×1080，60 fps，带原曲。
- `census_train_cut_1080p60.mp4`：3.383 秒，203 帧，按原镜头时长裁出的对接版本，带原曲。
- `encoded_contact_sheet.jpg`：从最终编码样片抽取的审片图。

验收已通过：两个视频完整解码成功；样片起、中、尾音轨相关性为 0.9863／0.9977／0.9873，在 16 kHz 检测中最大相关性均对应 0 ms 偏移。

画面采用黑、米白、血红的平面设计语言。统计卡是车上的货物，近景保留表头、编号与各不相同的打孔；远景由连续车厢构成曲线。红孔同时落下时，卡片的细红边一起出现，使远景仍能读到这一拍。

## 运镜

| 片内时间 | 动作 |
|---|---|
| 0.00–0.48 s | 追随一张统计卡，暗红光褪去，读清表头。 |
| 0.48–2.534 s | 连续拉升和转向；距离按对数变化，相机的注视点延后移向全局，保住卡片的空间位置。逐步揭示卡片叠层、车轮与长列车厢。 |
| 2.534 s | 对应原曲 EXECUTION：全部卡在同一位置出现红孔；细红边让远景形成一道红线。 |
| 2.534–3.384 s | 远景缓慢漂移，弯道、机头、蒸汽和工厂同框。此处可接回原片。 |
| 3.384–5.383 s | 独立样片的延长尾段，机头继续接近工厂入口。 |

## 技术

Python/NumPy 计算三维轨道、车体姿态、相机与投影；Pillow 绘制平面多边形和透视卡面，2 倍超采样后缩至 1080p。画面用程序生成，字体来自本机。FFmpeg/NVENC 编码 H.264，按源时间裁取原 MP3，并编码 AAC 320 kb/s。没有补帧。

轨道按弧长采样，车厢保持间距，前后转向架分别顺应轨道方向；车轮与机头连杆按行进距离转动。蒸汽为分层的版画式墨云，风向随轨道切线指向后方。排序和局部透视贴图保留叠层遮挡，无需引入大型场景软件或外部模型。

独立源代码：`render.py`。验收：`verify.py`。`render_manifest.json` 记录源音频哈希和实际导出参数；`verification.json` 记录全片解码与起、中、尾音频相关性。
