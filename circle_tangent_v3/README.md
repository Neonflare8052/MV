# 圆周接住 → 半圈送出 → 切线承托

第三次动作打样，原曲 33.4–40.7 秒，7.3 秒，1080p60，原曲音轨。原工程与前两版保留。

## 两个镜头，一次连续动作

1. 白球从画面左上方外部飞入。圆周变为半透明矢量带，在 34.58 秒接住白球；球的运动平滑接入圆周内侧。
2. 白球沿内缘运动恰好 180°，接触处有随行的暖色亮弧。36.287 秒，白球沿圆周切线方向脱离并继续飞行。
3. 37.0667 秒（片段第 220 帧）硬切到点云波面。点云圆体与圆周矢量带直接消失；白球在新摄影机下匹配切镜前的屏幕位置、速度与大小。运动模糊采样也限制在各自镜头内，避免切镜残留圆圈。
4. 白球继续走空中弧线。中央切面在落点下方提前展开；38.78 秒接住白球，整体轻微下沉后恢复稳定。39 秒以后，两片相邻切面跟进，镜头向承托区域靠近。

圆周内缘半径为 2.10，白球半径为 0.105，其绕行半径为 1.995。第二镜的运动通过摄影机坐标匹配衔接，飞行终点落在真实切平面上。落地的小幅下沉同时作用于点云高度场、切面与白球。

`render.py` 控制轨迹、切镜和摄影机；GLSL 绘制点云、半透明矢量面和白球。没有歌词或数值标注。全部画面由代码生成，音轨来自本地原曲。

`check_motion.py` 检查外部入画、180° 绕行、切向出射、切镜位置/速度/大小衔接、入画可见范围及落地接触。`verify.py` 检查成片规格、完整解码、三段原曲同步和原文件哈希。`source_manifest.json` 在本次制作开始时采集，涵盖原工程及上一版文件。

运行：先执行 `render.py`，再执行 `check_motion.py` 和 `verify.py`。`--stills` 接受逗号分隔的原曲时间，用于查看关键帧。
