# 半透明背景打样 v2

原曲 33–41 秒，8 秒，1920×1080 / 60 fps，原曲音轨。所有输出位于这个独立文件夹，原工程和上一版保留。

将上一版的暗线切片重做为有面积的半透明数学截层：环带上能看到等值线和横截线，层与层的叠透关系可见；它们随后展开为波面。后方保留三条旧圆弧，延迟展开和消退。前景点阵与运镜沿用原场景，没有歌词或参数标注。

默认背景强度经过关键帧对照后设为 0.45，以保留可读的曲面轮廓，同时让前景点阵保持更高亮度。`render_manifest.json` 记录实际导出参数；`verification.json` 记录视频规格、解码、原始输入哈希和三处音频同步结果。

`v1_vs_v2_38.8.jpg` 使用两版编码后同一时刻的抽帧：左为上一版，右为新版。
