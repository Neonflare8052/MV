# 《world.execute(me);》MV 第一版分镜（歌词已移除）

> 原文件含完整歌词，歌词版权归 Mili，此公开版本移除了歌词列，只保留时间点与镜头对应。

本文件以本轮讨论形成的方案为准，替代最初 44 镜版本；初稿原样保存于 [work/storyboard_initial.md](work/storyboard_initial.md)。主角是精密、冷静的几何 AI。科学机制、计算史与主体关系通过具体动作呈现；剧情是 MV 创作解释，不宣称为作者的官方设定。

## 制作规格

- 主交付：`output/world_execute_me_4K60.mp4`，3840×2160、60 fps、16:9。三维场景和二维程序画面均在 4K 目标上渲染，不把低分辨率整帧放大充当 4K；设计坐标可用 1920×1080。
- 画面：真实三维网格、透视相机、材质／光照与可编程二维图形混合。实体计算层、眼睛结构、计时器、天体、曲面屏幕、纸带机器与刀架有空间和物感；ASCII、卡通、数学图形与现代对话界面保持各自明确的二维规则。
- 唯一音乐源：本目录 `Mili - world.execute (me) ;.mp3`。文件标记时长 211.957551 秒；LRC 只有起点，不能据此声称逐帧听音校准。保留原曲，不混入相邻工程的 M4A 或重新演绎音轨。画面末帧覆盖音乐结束。
- 字幕：不烧录歌词；提供 [output/lyrics.srt](output/lyrics.srt)。129 个原始 LRC 标记全部映射，16.000 秒歌名为间奏定位，不作演唱字幕；其余 128 条生成独立字幕，每条至下一标记或最多 5 秒，不让长空档一直挂着上一句。演唱延音的精修仍以听音为准。
- 程序动画：按绝对秒数求值，固定随机种子，可重播与单帧定位。最终导出连续真实 60 fps；卡顿是指定片段的剧情效果，不降低整个视频帧率。
- 验证：`python src/validate_movie.py` 检查尺寸、帧率、时长、音轨、全流解码，并比较源音乐和成片解码音频的起／中／尾。结果写 `output/verification.json`；该检查不能替代视觉审片，也不能单靠容器尺寸证明原生渲染。

## 统一的视觉规则

- 00:00–00:51.363：深黑／石墨灰、纯白陶瓷、铜金导体。金属靠反射显形，少量状态灯才发光；避免随机粒子、泛用霓虹和无意义飞线。
- 从时间倒流开始出现自然颜色：天空反射、齿轮材质、日光、行星与高温物质。之后各场景可保留必要色彩。卡通与纸带底色是温和米白 `#F2EBDD`，黄色代表警告，红色用于系统判定与 EXECUTION。
- 圆的运动／缺口／比例作为主角连续特征。COMPLETION 是短暂完整，DISHEARTENED 后固定缺口；结尾聊天头像认得出同一主体。转向寻找是三维朝向变化和停顿，不是加载图标式旋转。
- “你”主要通过输入、回应、恒星轨迹与心电信号被感知。白点在数学段承担局部互动，不强迫所有白点永久代表同一角色。
- 两次 ASCII 使用同一份平面眼睛主图和同一网格，前段红字 SIMULATION、尾段 EXECUTION／TCP 状态。字符格清屏是随机离散状态切换为米白块，没有真实旋转、粒子飞散或立方体翻面。
- 故障递进：exe 段是语言退化；空引用段是程序返回；断头台段才出现冻结／漏帧／重复；聊天保持整洁；最后 TCP 正常关闭。避免全片同一种闪烁。

### 医疗伪代码、空引用与正常关闭

医疗段使用片内伪代码，例如 `execute(assess_autonomic_state(subject))`、`execute(simulate_analgesia(subject), feedback="self_report")`；它们是模拟表达，不是医学操作。生理数据与满足度估计分开；不确定区间不会被无理由清零。

寻找段应当能读到短调用和真实类型的错误：Python 的 `None` 调用、JavaScript 的 `null` 属性访问、Java 的 `NullPointerException`。`ILLEGAL ARGUMENTS` 作为主角给出的上层判断，不冒充所有语言相同的原生错误。

尾段展示一种正常 TCP 关闭序列，按观众可读速度排布：

```text
CLIENT → SERVER    FIN, ACK
SERVER → CLIENT    ACK
SERVER → CLIENT    FIN, ACK
CLIENT → SERVER    ACK

CONNECTION CLOSED
```

### 纸带计算机与聊天界面的连续性

老机器为致敬早期计算历史而出现。必须给机身、出口与正在运行的穿孔纸带一个可识别的连续镜头；纸带不是凭空飘出的打印纸。十二次执行完成介质揭示，六声计数将已建立的纸带带到刀下，避免两次重新介绍机器。

碎纸落地形成爱心只用一次俯视揭示；仍在输出的完整纸带留在上缘，镜头直接沿它推近。送纸上移与聊天滚动保持方向和速度连续，米白纸面成为 UI 底色。孔列到图片是视觉匹配，不伪称穿孔就是图像像素编码。

现代聊天至少三轮一问一答，信息以图片为核心并有简短真实请求；最后一轮结束后先等用户，才产生第二条连续 AI 消息。“我希望你留下。”须独立可读。最终 EXECUTION 前不安排点击关闭，不把无人回应与 TCP 断开提前合并。
