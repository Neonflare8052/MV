# 点云与矢量空间 · 第二次切线打样

原曲 33.4–40.7 秒，7.3 秒，1920×1080，60 fps，原曲音轨。

本版重新设计主体拓扑、尺度、运镜与接收者的运动，不沿用上一版的居中波面和落球动作。原工程、初稿与上次打样均保留；渲染器以独立副本复用。

## 镜头发展

- 33.4–36.8 秒：AI 的点云圆体以斜视角出现。外缘的一部分点逐渐交给连续的半透明圆周带，白色接收者移向这条边界。
- 36.86–38.17 秒：圆体展开为宽 10.8、深 6.6 的点云波面，镜头下压并绕向侧前方。波面进入前景，画面尺度发生明显变化。
- 38.36–39.4 秒：七片有面积的切面从各自切点沿两侧展开，点云相应带状区域减弱，实现从点到连续矢量面的交接。中央暖色面先建立，外围冷灰切面依次跟进。
- 38.6–40.7 秒：接收者周围的局部波动逐渐平稳，中央切面稳定承托它；外围点云继续运动。镜头向它靠近，前景切面掠过画面下缘，呈现叠透与空间尺度。

## 实现

Python 调度时间与摄影机，ModernGL / GLSL 绘制三维点云及解析半透明平面，沿用独立快照中的 HDR、抗锯齿与后期流程，FFmpeg 编码。没有歌词、数值参数或 HUD。

点云和七片切面共用同一个连续高度场及其偏导数。局部安定是高度场本身的变化，平面仍使用变化后的真实切向。透明面按每条视线排序；点云也计算被切面遮挡后的透射，白色接收者有遮挡和接触阴影。

`render.py` 为新场景调度；`common.glsl` 为几何关系；`scene.glsl` 为接收者和透明面；`points.vert` / `points.frag` 为新点云拓扑与着色。

`verify.py` 核验原文件哈希、分辨率、帧数、时长、完整音视频解码及三处原曲同步；结果见 `verification.json`。`encoded_contact_sheet.jpg` 从最终 MP4 抽帧，不是未编码预览。
